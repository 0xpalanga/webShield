# WebShield

**WebShield** is an automated command-line vulnerability scanner designed to help developers and security professionals detect common web application vulnerabilities such as SQL Injection, Cross-Site Scripting (XSS), and insecure open ports.

---

## 🔍 Features

- Automated port scanning using Nmap
- Vulnerability detection via custom scripts
- Simple command-line interface (CLI)
- Real-time scan reports
- Color-coded terminal output for easy readability
- Lightweight and modular design

---

## 📦 Technologies Used

- Python 3
- Nmap (`python-nmap`)
- Socket
- Requests
- Colorama
